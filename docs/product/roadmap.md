# Hoja de ruta

Una fase solo se marca como terminada tras superar sus pruebas y recibir aprobación.

| Fase | Nombre | Alcance | Estado |
|---|---|---|---|
| 00 | Fundación técnica | Entorno, repositorio, arquitectura, documentación | EN REVISIÓN (Sprint 01) |
| 01 | Sistema de diseño | Tokens, temas, componentes, navegación, pantallas base | PENDIENTE |
| 02 | Autenticación | Registro, login, recuperación, perfiles | PENDIENTE |
| 03 | Hogares | Creación, integrantes, invitaciones, roles y permisos | PENDIENTE |
| 04 | Inicio | Dashboard personalizado | PENDIENTE |
| 05 | Limpieza | Habitaciones, tareas, frecuencias, responsables | PENDIENTE |
| 06 | Compras | Listas colaborativas en tiempo real | PENDIENTE |
| 07 | Finanzas | Ingresos, gastos, presupuestos, cuentas compartidas | PENDIENTE |
| 08 | Calendario | Eventos, recordatorios, calendarios familiares | PENDIENTE |
| 09 | Recetas y menús | Recetario, ingredientes, plan semanal | PENDIENTE |
| 10 | Despensa | Inventario, cantidades, caducidad, movimientos | PENDIENTE |
| 11 | Mantenimiento | Activos, revisiones, garantías | PENDIENTE |
| 12 | Documentos | Almacenamiento privado/compartido (requiere modelo de amenazas) | PENDIENTE |
| 13 | Gamificación | Puntos, logros, mascota, carga doméstica | PENDIENTE |
| 14 | Automatizaciones | Conexión entre módulos | PENDIENTE |
| 15 | IA | Asistente, voz, OCR, sugerencias | PENDIENTE |
| 16 | Monetización | Planes, suscripciones, entitlements | PENDIENTE |
| 17 | Optimización | Offline avanzado, rendimiento, seguridad, accesibilidad | PENDIENTE |
| 18 | Beta | Pruebas con usuarios y dispositivos reales | PENDIENTE |
| 19 | Publicación | App Store, Google Play, lanzamiento | PENDIENTE |

Nota: el Sprint 01 cubre la Fase 00 y adelanta la base de la Fase 01
(tokens, temas y navegación) para tener una app ejecutable.
